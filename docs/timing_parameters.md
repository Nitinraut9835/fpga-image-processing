# LCD Timing Parameters

## Display: Terasic TRDB-LTM 4.3" 800×480

## Pixel Clock
- **Frequency:** 33.25 MHz
- **Generated by:** On-chip PLL from 50 MHz input

## Horizontal Timing
| Parameter | Value | Unit |
|-----------|-------|------|
| Active pixels | 800 | pixels |
| Front porch | 40 | clocks |
| Sync pulse | 1 | clock |
| Back porch | 215 | clocks |
| Total per line | 1056 | clocks |

## Vertical Timing
| Parameter | Value | Unit |
|-----------|-------|------|
| Active lines | 480 | lines |
| Front porch | 10 | lines |
| Sync pulse | 1 | line |
| Back porch | 34 | lines |
| Total lines | 525 | lines |

## Frame Rate
```
Frame rate = 33,250,000 / (1056 × 525) = 59.98 Hz ≈ 60 Hz
```

## Signal Polarity
| Signal | Active Level |
|--------|-------------|
| HD (HSYNC) | Active LOW |
| VD (VSYNC) | Active LOW |
| DEN | Active HIGH |
| NCLK | Rising edge samples data |
